# Visão Geral

**Devocionais Diários** é um projeto de desenvolvimento web criado com dois objetivos:

1. Disponibilizar reflexões cristãs diárias baseadas na Palavra de Deus.
2. Servir como ambiente prático de aprendizado em desenvolvimento web moderno.

O projeto está sendo desenvolvido seguindo práticas profissionais de planejamento, documentação, versionamento e construção incremental.

---

# Objetivos do Projeto

## Objetivo Funcional

Desenvolver uma plataforma para publicação e consulta de devocionais diários organizados cronologicamente.

## Objetivo Educacional

Utilizar o projeto como laboratório de aprendizado para:

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Hugo
- UX/UI
- Figma
- SEO
- Arquitetura de Informação
- Boas Práticas de Desenvolvimento
